# 面向高校实验室的轻量化智能自治运维系统 (LabOps-Agent)

> **最新版本**：`v2.4.0`（十四大核心扩展功能全量封板交付）  
> **质量基线**：后端自动化测试套件 **275 项 100% 绿灯全通过**，前端 Vite 5 生产打包零报错零警告。

LabOps-Agent 是一个**面向高校实验室的轻量化智能自治运维系统**。系统采用自研 ReAct（Reasoning + Acting）推理循环与 RAG 规程知识检索，集成了设备运行监控、故障报修闭环、管理规范问答以及设备借用登记等功能。

通过自然语言交互，Agent 可以解析运维意图并调用对应的业务工具，执行结果直接写入底层关系型数据库，并通过 SSE（Server-Sent Events）事件流驱动前端大盘实时局部刷新。

---

## 技术栈

- **前端**：Vue 3、Vite、Tailwind CSS、Pinia
- **后端**：FastAPI、Python 3.14、Pydantic、SQLAlchemy
- **数据与检索**：SQLite（业务数据）、ChromaDB（本地规章向量库）
- **网关与容器化**：Docker、Docker Compose、Nginx

## 核心功能

- **商业大模型多级容灾与三级弹性降级架构 (FEAT-14)**：针对外部商业化大模型 API（如 DeepSeek 云端服务器故障、宕机或网络限流）引起的系统不可用风险，统一抽象 OpenAI 兼容协议构建「主通道（DeepSeek） ➔ 备用通道（阿里通义千问 Qwen） ➔ 本地确定性自治运维大脑（Mock Brain）」三级容灾流水线。集成 Fail-Fast 毫秒级连接超时熔断，杜绝前端假死挂起；思考卡片自适应多通道切换，坚决剔除生硬中括号标签，以自然严谨的学术工科语体无痕记录通道流转轨迹，保障高校实验室运维在断网、上游崩溃或无 Key 状态下全天候 100% 业务高可用与答辩演示免死金牌闭环。
- **全机房主动自治巡检与《运行健康研判简报》出具 (FEAT-01)**：一键发起或口语化调度硬件探针巡查全网设备，识别温度超 40℃ 红线或掉线异常；自动联动 RAG 安全规程与防重复建单闭环，计算综合健康指数（0~100分）与运行态势等级，出具微光研判简报，扣紧论文“自治”题眼。
- **纯正明亮版白底 A4 PDF 打印导出引擎**：采用独立沙箱 iframe 打印隔离机制，动态组装符合高校官方标准的白底彩色 A4 研报文档，保留高精 SVG 仪表盘与色彩饱和度，彻底根除主窗口溢出导致的 PDF 导出白板问题。
- **机房机柜 2D 机位拓扑视图与数字孪生拖拽调度引擎 (FEAT-02 & FEAT-08)**：基于 `ServerRack` 模型实现物理机房与机柜全生命周期动态化持久管理与安全防误删联锁；构筑等高水平对齐底座与 42U 工业仿真标尺；在架设备与周边仪器全面支持原生 HTML5 拖拽上架、跨机柜调拨与实时 U 位碰撞越界检测，释放后自动发起 API 更新并即时重载大盘。
- **运维工单流转与资产履历时序时间轴 (Timeline Drawer, FEAT-03)**：提供通用微光时间轴抽屉，全时序串联提单创建、审批流转、Agent 审计调用节点与借还履历；落实流转处置人实名审计防抵赖，受理与办结时支持录入处置小结备忘，支持点击穿透唤起人物/智能体全景档案弹窗（`UserProfileModal`）。
- **规章规程知识中心与 RAG 向量切块动态闭环 (Regulations Center, FEAT-04 & FEAT-09)**：面向高校管理制度，提供沉浸式阅读、多维检索、安全红线彩色微光胶囊高亮与“向 AI 咨询”对话直达联动；全面支持规程动态录入、在线修订与废止下线，语义切块重算与 ChromaDB 向量库毫秒级落盘同步；白盒化展示底层 RAG 向量切块与余弦相似度百分比。
- **资产借用超期智能预警、催告函与站内待办闭环 (Overdue Notice, FEAT-05)**：底层自动核验资产借调期限与超期天数，资产台账高亮红色微光呼吸徽标（`⚠️ 逾期 18天`）与超期快速筛选；出具标准高校红头公文排版、加盖仿真红章、硬件规格网格与规章违约责任条款的《资产超期归还督促催告函》（`OverdueNoticeModal`）；支持下发站内待办通知（`UserNotification`），借用教师登录即时微光浮窗感知并直达归还闭环。
- **资产台账与工单明细一键导出 / 纸质打印归档 (Export & Print Archive, FEAT-06)**：资产台账与工单库支持按当前过滤视图（分类胶囊/状态筛选/关键词搜索）一键导出含 UTF-8 BOM 的标准 CSV，兼容微软 Excel / WPS 打开零乱码，内置公式注入安全防护；支持调用独立沙箱 iframe 打印引擎，隔离暗黑主题，输出带重点实验室官方抬头、经办人实名、统计范围与三方签字归档栏的纯白底 A4 纸质清册。
- **浏览器原生语音交互与高危告警 TTS 播报 (Web Speech STT & TTS Alert, FEAT-07)**：AI 对话输入框集成原生 Web Speech API 麦克风录音（STT），支持中文长语音实时识别并平滑追加至指令输入框，带红色呼吸微光动效与生命周期防竞态；在全网自治巡检控制台集成高危告警 TTS 语音播报开关（**默认处于静音关闭安全状态**），当巡检检出核心设备超温（$\ge 40^\circ\text{C}$）或脱网掉线时，自动通过原生 `SpeechSynthesisUtterance` 干练播报自然语言警报，零外部重型依赖。
- **端到端全链路 RBAC 细粒度权限联锁与安全盾牌卡片 (FEAT-10)**：严格三权分立，注册身份按权限正向排序并部署教师（`teacher666`）与管理员（`admin666`）双重安全激活口令；工单流转落实权属隔离防护（教师仅可编辑本人发起的工单，管理员维护全局工单）；学生敏感写操作（借机、改状态、办结工单）一律硬拦截并以专属安全盾牌卡片渲染，内置行内 Markdown 渲染引擎与结构化数字指引分行排版；当前登录人支持自主维护资料与修改密码。
- **物理机柜 0~42U 插槽排他性冲突防御与拓扑防重联锁体系 (FEAT-11)**：新增/编辑设备时执行 `[start_u, start_u + u_height - 1]` 垂直区间排他性占用算法，编辑时排除自身在架区间；下拉选框以暗淡字体和横向中划删除线无障碍语义直观展示已被占用插槽，剔除冗余“空闲可用”标签；机房物理编号与地理位置全局防重校验，冲突原位弹窗呈现，保障用户交互心流。
- **全域设备口语简称智能解析与双轨 AI 驱动工单闭环引擎 (FEAT-12)**：底层 `resolve_asset` 解析器全面纳管教学实验台、渗透实验箱、精密空调及口语化简称与“机房+设备名”模糊映射；提示词铁律约束大模型零幻觉、感知优先；实现“左侧对话 AI 调度流”与“右侧 UI 弹窗自然语言语义提取流（`ticket_comment_analyzer.py`）”双轨工单办结，从处置说明提取真实实测温度回写在架设备台账，消除静态硬编码，沉淀 `[AI验收审计]` 结构化时序记录。
- **实验室规章安全红线管控、第一性原理单向真理源健康度重构与权限中枢极简净化 (FEAT-13)**：规章规程创建与修改实行严格管理员权限硬隔离（普通教师/学生越权拦截 403）；角色权限看板彻底剔除冗余提示词，重塑直观简约指引；基于第一性原理彻底废除资产台账健康度下拉调节框，确立由实时遥测温度与在线状态单向决定的客观真理源徽章；全域状态标签统一自然中文化（正常/预警/超温/离线）；工单终结归档节点（CLOSED）剔除冗余排障输入实现一键优雅闭环；超期催收站内待办构建“未读紧急督促 ➔ 已读未还警示保持 ➔ 设备归还自动收敛（Compact Pill） ➔ 点击展开历史追溯”三阶全景交互状态机。
- **对话流高保真 GFM Markdown 表格排版引擎**：在左侧聊天流支持词法级表格解析，将设备台账渲染为带横向自适应滚动条（`overflow-x-auto`）、细边框、斑马纹与微光磨砂的结构化数据视窗，支持引用块与分割线，函数式回调杜绝字符吞噬与代码/加粗冲突。
- **右侧看板现代 CSS 原生容器查询与弹性自适应**：引入现代 CSS 原生容器查询（`@container`），基于组件局部物理视口驱动响应式网格与自适应弹性排版，保障左右分栏动态拖拽时数据与指标卡片的优雅呈现。
- **ReAct 智能调度与双模大脑**：基于状态机实现 Thought-Action-Observation 闭环，将自然语言请求拆解为明确的工具调用链路；支持商业大模型（DeepSeek/OpenAI 兼容端点）与确定性本地 Mock 规则大脑无缝切换。
- **RAG 规章知识库**：基于本地向量数据库检索机房管理规范与安全应急条例，回答包含引用来源溯源。
- **业务双向联动**：对话中触发的报修提单、状态变更与设备借调直接写入数据库，前端看板无感自动局部增补刷新。
- **设备硬件参数台账与轻量悬浮面板**：设备资产从静态展示升级为包含硬件配置（CPU/内存/GPU/存储/功耗/核心温度设定）、出厂编号等丰富参数的动态详情，配备不遮挡全屏的圆角微光浮窗卡片（`DeviceDetailModal`）。
- **全景双模态（明亮/暗黑）高质感拟态**：全系统组件深度适配深邃暗黑磨砂与通透冰晶白风格，登录鉴权弹窗（`AuthModal`）与设备浮窗全面消除发灰暗沉，视觉体验高度统一。
- **结构化流式交互**：前端通过 SSE 实时分发思考过程折叠框、工具调用卡片、规章溯源徽标与最终回复。

## 快速开始

### 方式一：Docker Compose（推荐）

需确保本机已安装并启动 Docker。

```bash
# 构建并后台启动全部服务
docker compose up -d --build

# 查看服务运行状态
docker compose ps
```

启动完成后可直接访问：
- **Web 前端大盘**：`http://localhost`
- **Swagger 接口文档**：`http://localhost/docs`
- **后端健康检查**：`http://localhost/api/health`

如需停止服务：
```bash
docker compose down
```

---

### 方式二：一键脚本运行

项目内置了环境自动适配启动脚本：
- **Windows**：双击运行根目录下的 `start.bat`（停止服务双击 `stop.bat`）
- **Linux / macOS**：在终端运行 `./start.sh`（停止服务运行 `./stop.sh`）

脚本会自动检测系统环境：若检测到 Docker 则优先使用容器启动；若无 Docker 环境则尝试拉起本地 Python 虚拟环境与 Vite 服务。

---

### 方式三：本地开发模式

#### 1. 后端服务 (FastAPI)

```bash
cd backend

# 创建并激活虚拟环境 (Windows PowerShell)
python -m venv .venv
.\.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 运行单测
pytest tests/

# 启动开发服务器
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

#### 2. 前端服务 (Vue 3)

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建
npm run build
```

前端本地开发地址为：`http://localhost:5173`。

---

### 方式四：纯终端 CLI 体验

无需启动前端，可在终端直接体验 ReAct 循环调度：

```bash
cd backend
python demo_cli.py
```
Windows 用户亦可直接双击运行 `scripts/run_cli.bat`。

## 环境配置

复制配置模板即可开始使用：

```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

核心配置项说明：

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `AGENT_MOCK_MODE` | `auto` | `auto`：未配置 API Key 时自动启用内置 Mock 调度器，已配置时自动调用外部大模型；<br>`mock`：强制使用内置确定性 Mock 调度器（离线可用）；<br>`real`：强制使用真实大模型 |
| `OPENAI_API_KEY` | *(空)* | 模型服务商 API Key（如 DeepSeek、OpenAI 等） |
| `OPENAI_BASE_URL` | `https://api.deepseek.com/v1` | 兼容 OpenAI 格式的接口地址 |
| `OPENAI_MODEL_NAME` | `deepseek-chat` | 模型名称 |
| `PORT` | `8000` | 后端服务监听端口 |

> **提示**：系统在未填写 API Key 时默认以 `auto` 模式运行，可直接通过内置 Mock 逻辑体验完整的业务链路。

├── docs/                     # 架构与技术文档

├── stop.bat / stop.sh        # 跨平台一键停止脚本
