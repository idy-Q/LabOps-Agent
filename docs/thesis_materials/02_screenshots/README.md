## 一、 数据库与后台 API 支撑截图（阶段 1）

1. **`01_swagger_api_docs.png`**（RESTful API 契约与接口文档）：
   - **操作步骤**：启动后端服务后，浏览器访问 `http://127.0.0.1:8000/docs`。
   - **截取内容**：包含 `/api/tickets/`、`/api/assets/`、`/api/chat/` 的完整 FastAPI Swagger UI 接口大盘。
   - **论文用途**：论文第 4/5 章证明前后端分离规范与 RESTful 接口体系的完备性。

2. **`02_sqlite_database_tables.png`**（物理数据库表结构与持久化）：
   - **操作步骤**：在 VS Code 中使用 `SQLite Viewer` 或通过 Navicat / DBeaver 打开 `backend/app/data/labops.db`。
   - **截取内容**：展示 `tickets`（工单）、`assets`（资产台账）、`audit_logs`（工具调用审计日志）与 `chat_histories`（会话与思考链表）表字段与数据。
   - **论文用途**：论文第 4 章数据库物理结构实现图。

## 二、 前端人机交互与视觉表现层截图（阶段 4 / 现代化 UI 重塑）

3. **`03_dashboard_glassmorphism_overview.png`**（全景玻璃拟态运维大盘）：
   - **操作步骤**：浏览器打开前端 `http://localhost:5173/`。
   - **截取内容**：包含顶栏高保真矢量 Logo、Codex Canvas 硬件加速流体背景、左侧 ReAct 会话视窗与右侧监控指标/工单/资产看板的全景图。
   - **论文用途**：论文第 5 章“系统主界面与人机交互设计”核心大图，体现现代化 Glassmorphism 工业级交互质感。

4. **`04_glass_effect_controller.png`**（视效调节浮层与个性化配置）：
   - **操作步骤**：点击顶栏右上角【视效】胶囊按钮展开调节浮层。
   - **截取内容**：展示【纯透清澈 / 平衡毛玻璃 / 深邃亚克力】3 档预设以及透明度/模糊度无级滑块调节卡片。
   - **论文用途**：论文第 5 章中作为“人机工程学与自适应视觉表现层实现”的技术插图，展示 LocalStorage 持久化与 CSS 响应式变量层级控制。

5. **`05_react_agent_reasoning_and_tools.png`**（ReAct 深度思考与工具调用卡片）：
   - **操作步骤**：在左侧对话框输入：`“查询DEV-SRV-201监控指标，若异常请自动提单”`。
   - **截取内容**：展开“深度思考过程（Thought）”折叠框，展示大模型逻辑推导链、`get_device_metrics` 和 `create_ticket` 的工具调用参数与返回卡片。
   - **论文用途**：论文第 5 章“智能自治运维调度流程实现”最核心插图，证明系统为真 Agent 推理决策，绝非静态套壳。

6. **`06_bidirectional_state_mutation.png`**（左右分栏双向数据联动与工单闭环）：
   - **操作步骤**：提单或更新工单状态后，观察右侧工单大盘。
   - **截取内容**：左侧 Agent 输出“已完成高优先级工单创建”，右侧工单表格第一行带有黄色脉冲高亮与最新生成的 `TK-` 工单编号。
   - **论文用途**：证明 Agent 与关系型业务数据库的双向实时联动闭环（SSE 事件驱动局部无感刷新）。
