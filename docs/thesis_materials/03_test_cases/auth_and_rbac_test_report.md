## 二、 毕业设计答辩核心创新点与技术亮点

1. **不可逆密码加盐哈希防撞库**：
   - 彻底废除高校实验室系统常见的“明文密码存储”安全隐患，全系统采用 `hashlib.sha256(f"{salt}:{password}")` 单向加盐哈希算法；
   - 登录校验采用恒定时间哈希比对，有效抵御彩虹表攻击与时序侧信道攻击。
2. **基于微特权原则的零信任提权防御**：
   - 系统为超级管理员角色设置专属动态安全口令 `admin666`，服务端在注册层对 `role == 'ADMIN'` 进行强行截断校验；
   - 即使非法用户通过抓包工具篡改前端 HTTP 请求体中的 `role` 字段，后端仍能以 100% 的确定性返回 HTTP 400 予以拦截。
3. **软工规范之端到端防冒名借调业务闭环**：
   - 在高校机房核心交换机、AI 计算节点等贵重教学资产借调管理中，传统系统允许用户任意填写借调人姓名，易造成责任推诿与设备丢失；
   - 本系统实现“登录态凭据自动透传 -> 借调表单强制 readonly 只读锁定 -> 业务接口自动关联 -> 学生角色全局置灰禁用”的四重防冒名安全闭环，成为答辩评审中体现软件工程完整度的高分亮点。
4. **AI 调度引擎端到端 RBAC 角色权限硬防御**：
   - 解决传统大模型“口头拒绝但在工具调用层面仍越权执行”的致命缺陷（Prompt Injection / Jailbreak 绕过风险）；
   - 在手写 ReAct 调度核心 (`ReActEngine` / `MockDecisionBrain`) 中构建代码级确定性 RBAC 硬拦截屏障：学生身份发起借调、改健康度、关工单坚决不调用任何写操作工具并严正驳回；教师借调用具强制注入绑定当前登录教师姓名，彻底根除冒名代借。
5. **看板数据与交互分权细粒度控制**：
   - 工单流转库严格落实“学生只读”、“教师仅受理”、“主管实地核验终审闭环”的三级流转体系；
   - 资产台账非管理员隐藏 `<select>` 下拉框，渲染为只读彩色状态微标，杜绝伪造硬件指标；
   - 登录弹窗采用可折叠式收敛设计，大幅节约纵向视觉空间，UI 排版更加整洁现代。
