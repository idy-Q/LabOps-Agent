### [FEAT-01] 全机房主动自治巡检与《运行健康研判简报》生成

  * **权威简报呈现**：出具通透磨砂玻璃微光的《高校实验室 IT 基础设施运行健康研判简报》模态弹窗，集成 SVG 环形进度态势仪表、四大核心 KPI、异常设备明细、条例溯源、工单穿透跳转、一键复制 Markdown 报告；
  * **纯正明亮版白底 A4 PDF 打印引擎**：构建独立沙箱 iframe 打印引擎（`buildLightPrintDocument`），100% 隔离主界面暗黑 DOM 样式并保留矢量色彩，彻底根治主窗口 `overflow-hidden` 导致的 PDF 白板缺陷，输出纯正白底高校官方研报；
  * **对话流 GFM Markdown 表格排版引擎**：在 `ChatStream.vue` 中升级 `renderMarkdown`，实现词法级表格解析与带横向滚动的 HTML 表格视窗，支持引用块与分割线，彻底免疫特殊字符吞噬与代码/加粗冲突；
  * **右侧看板现代 CSS 原生容器查询重构**：在 `OverviewBento.vue` 为资产健康卡片声明 `@container (min-width: 320px)`，在分栏拖拽挤压时自适应切换为“圆环在上 + 2x2 对称网格”，强制 `whitespace-nowrap shrink-0` 根治汉字竖排拆字；分栏拖拽区间锁定为 28%~58% 并设 `min-w-[420px]` 底线；
  * **交付产物**：后端业务内核 `patrol_service.py`、工具 `patrol_tools.py`、前端弹窗 `PatrolReportModal.vue`、全量 129 项单元与集成测试、免安装便携整合包同步流水线。
