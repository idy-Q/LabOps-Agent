### [FEAT-07] 浏览器原生语音交互与高危告警 TTS 播报 (端云协同声学告警与高可用离线容灾体系)
* **当前状态**：**✅ 已完成并全量测试通过 (v1.8.1)**
* **功能概述**：
  * **纯前端零依赖极简架构（KISS 原则）**：
    * 坚决不引入外部重型依赖，零后端接口变动、零数据库实体修改，全仓 201 项单测基线 100% 保持；
    * 完全基于 W3C 标准 Web Audio API 与 Web Speech API（`SpeechRecognition` 与 `window.speechSynthesis`），便携包零体积增加；
  * **对话输入框原生 STT 实时语音转文字**：
    * 在 `ChatInput.vue` 发送按钮旁集成紧凑的麦克风按钮，支持中文长语音实时识别并平滑追加至指令输入框；
    * 录音过程中呈现红色呼吸微光脉冲动效与麦克风高亮，点击可随时中止；在不支持环境优雅降级隐藏，保障零运行时异常；
  * **全网巡检高危告警端云协同声学告警与高可用离线容灾（TTS 4级增强）**：
    * **交互语义与静音管控**：遵循规范，告警语音播报**默认保持静音关闭**；在 `OverviewBento.vue`「发起全网自治体检」旁设置紧凑的开关切换按钮（🔊 开启 / 🔇 静音），开启后方在检出超温、掉线等高危告警时触发自然语言声学告警；
    * **0 毫秒原生 Web Audio 先导和弦音（Earcon / Pre-chime）**：基于原生 `AudioContext` 纯代码实时合成双频上行和弦（主频 880Hz 爬升至 1320Hz，配合 1760Hz 空间泛音与 15ms 线性抗爆音起振包络），在告警触发第 0 毫秒即时发声，彻底消灭云端网络首包等待带来的感官空白；
    * **主用高保真云端自然音（微软晓晓 Neural TTS）**：优先动态绑定高保真神经网络发音人（`Microsoft Xiaoxiao Online (Natural)`），提供清脆、生动的自然语言播报；
    * **静默长连接链路预热（Pre-warming）**：页面初始化及语音列表注入完成后，自动发送 0.01 极低微音微指令，提前建立 Edge 与微软云端长连接通道与 SSL 握手，大幅压降首次告警冷启动延时；
