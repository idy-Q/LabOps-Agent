## 二、 核心功能完备性对照说明

本套图表坚决摒弃“为简化排版而阉割系统核心”的做法，全面真实反映了本系统的核心灵魂与工程创新点：

### 1. 系统功能结构图 (图 3-1)
- **机房管理员端 (11项)**：规程源文档维护、知识切块台账管理、Agent工具审计审查、设备借调归还验收、工单流转处置留痕、运维工单全量处置、硬件物理规格维护、实验设备资产管理、机房区域与配电台账、用户角色与权限管理、后台安全认证登录。
- **师生用户端 (11项)**：知识依据溯源展示、机房安全规程咨询、大盘双向联动看板、个人工单进度跟踪、设备故障在线报修、归还借调设备登记、设备实名借调申请、硬件物理规格查看、实验设备在库查询、新用户注册与登记、前台用户账号登录。
- **智能自治Agent端 (8项)**：宿主机指标自主感知、超温故障自主研判提单、手写ReAct状态机调度、Function Calling工具分发、ChromaDB向量检索、规程溯源依据生成、细粒度SSE流式响应、工具行为物理落盘审计。

### 2. 系统用例图 (图 3-2)
- **学生用户 (STUDENT)**：轻量交互、基础规章问答与报修。
- **指导教师 (TEACHER)**：设备实名绑定借调、归还核验、教学工单流转协同。
- **机房管理员 (ADMIN)**：admin666口令提权、全量工单闭环、资产调配、规程切块维护。
- **智能自治 Agent (AI ACTOR)**：指标主动感知、超温研判提单、ReAct思维链推理、工具调用审查、向量溯源、SSE大盘局部推送、物理落盘审计。

### 3. 整体 E-R 图 (图 3-4)
- 真实映射底层 SQLAlchemy 数据库模型，展现机房台账与设备资产、资产与硬件规格、设备与借调、工单与流转、文档与切块的实体联系与基数映射（1:1、1:n）。

## 三、 浏览与使用指南

1. **直接查看**：双击打开本目录下的 `index.html`，即可在浏览器中高保真预览三张矢量图，支持一键放大与原生矢量查看。
2. **Word 论文插入**：Microsoft Word 原生支持直接插入 `.svg` 矢量图，插入后缩放无失真，打印具备出版级超清墨线效果。
3. **几何零交叉验证**：可通过 Python 运行工程内置的线段求交检测脚本，交点数均为 0。
